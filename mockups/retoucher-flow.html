Notes for engineering

  1. RetouchDetail = { id, product_id, source_image_id, rect(x,y,w,h as 0–1 fractions), name, thumb }. Stored on the product, so it is reusable across every generation and every batch.
  2. Crops are kept as fractions of the source image, never pixels — the same detail then works against 1K and 4K outputs alike.
  3. A retouch job carries: parent_image_id, zone rect, prompt, detail_id (nullable). The zone is padded before it goes to the edit model so it can blend the seam.
  4. Output inherits parent.tags and appends retouch, and stores parent_id — so it stays inside the same product/batch filters and the before/after diff is free.
  5. Retouches chain: a retouched image is a valid parent (_r1 → _r2). Keep the retouch tag once and track depth separately.
  6. The popup anchors to the drawn zone and is clamped inside the image; below 760px it becomes a bottom sheet.
  7. Prompt-only retouch (no detail attached) must stay valid — the detail picker has a none option.

Static mockup — generation is simulated, no backend calls. Placeholder artwork stands in for real product photos.
